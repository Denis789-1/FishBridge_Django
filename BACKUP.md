# Резервное копирование базы данных

Для ручного создания копии SQLite из корневой папки проекта выполните:

```powershell
python manage.py backup_database
```

Копии сохраняются в папку `backups`.

## Ежедневный запуск в Windows

1. Откройте «Планировщик заданий».
2. Создайте простую задачу с ежедневным запуском.
3. В поле программы укажите путь к `python.exe` из виртуального окружения проекта.
4. В аргументы добавьте `manage.py backup_database`.
5. В поле рабочей папки укажите корневую папку проекта, где находится `manage.py`.
6. Запустите задачу вручную один раз и проверьте появление файла в `backups`.

## Восстановление

1. Остановите Django-сервер.
2. Скопируйте выбранный файл из `backups` в корневую папку проекта.
3. Переименуйте копию в `db.sqlite3`, предварительно сохранив текущую базу отдельно.
4. Запустите сервер и проверьте данные.

Резервная копия создаётся через SQLite Backup API, поэтому её создание не зависит от простого копирования открытого файла базы.
